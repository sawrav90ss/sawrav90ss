### 🚀 Featured project

#### [🧹 srt-clean](https://github.com/sawrav90ss/srt-clean)

Free up space on your Mac or Windows PC with one command, without losing anything you need. It finds the caches of every app, skips the apps you're using and asks before deleting anything.

**🍎 Mac**, in Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/sawrav90ss/srt-clean/main/srt-clean.sh | bash
```

**🪟 Windows**, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/sawrav90ss/srt-clean/main/srt-clean.ps1 | iex
```
